# Royal Dedale

  -> Un jeu d'exploration (inspiré du jeu Blue Prince) dans lequel le joueur se déplace dans un manoir, afin d'atteindre la sortie en plaçant et traversant des tuiles dont les caractéristiques diffèrent.

 la page du projet : https://www.labri.fr/perso/renault/working/teaching/projets/2025-26-S5-RoyalDedale.php

 Ce projet est codé en language C et a pour objectif de mettre en pratique les connaissances vues en cours sur ce language de programmation ainsi que se familiariser avec le travail en équipe et l'utilisation du dépôt git.

# Compilation : make

# Exécution : ./project
  paramètres possibles :

-s <entier> : pour initialiser la graine du générateur aléatoire
-t <entier> : argument de la fonction init_tiles
-n <entier> : nombre maximum de tours de jeu possibles
-i : version interactive pour pouvoir jouer
-g : visualiser la représentation graphique du jeu

# Tests : make test ( Après la compilation !! )
